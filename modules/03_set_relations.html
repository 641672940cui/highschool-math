📘 期中/期末★ 基础
（2024 广州期末）已知集合 \(A = \{1, 2\}\)，\(B = \{1, 2, 3\}\)，则 \(A\) 与 \(B\) 的关系是（ ）
A. \(A \subseteq B\)
B. \(B \subseteq A\)
C. \(A = B\)
D. \(A \not\subset B\)
A 中所有元素 1,2 都在 B 中，所以 \(A \subseteq B\)。
📘 期中/期末★ 基础
（2023 深圳期末）下列集合中，与 \(\{1, 2, 3\}\) 相等的是（ ）
A. \(\{1, 2\}\)
B. \(\{3, 2, 1\}\)
C. \(\{1, 2, 3, 4\}\)
D. \(\{0, 1, 2, 3\}\)
集合相等不看顺序，\(\{3, 2, 1\}\) 与 \(\{1, 2, 3\}\) 元素完全相同。
📘 期中/期末★ 基础
（2024 佛山期末）已知集合 \(A = \{x \mid x \text{ 是正方形}\}\)，\(B = \{x \mid x \text{ 是矩形}\}\)，则（ ）
A. \(A \subseteq B\)
B. \(B \subseteq A\)
C. \(A = B\)
D. \(A \not\subset B\)
所有正方形都是矩形，所以 \(A \subseteq B\)。
🎯 高考★ 基础
（2022 广东高考改编）已知集合 \(A = \{1, 2, 3\}\)，则集合 \(A\) 的子集个数为（ ）
A. \(3\)
B. \(6\)
C. \(7\)
D. \(8\)
有 3 个元素，子集个数为 \(2^3 = 8\)。
📘 期中/期末★ 基础
（2024 东莞期末）已知集合 \(A = \{0, 1, 2\}\)，则集合 \(A\) 的真子集个数为（ ）
A. \(3\)
B. \(6\)
C. \(7\)
D. \(8\)
真子集个数 = 子集个数减去本身 = \(2^3 - 1 = 7\)。
📘 期中/期末★★ 中档
（2023 广州期末）已知集合 \(A = \{1, 2\}\)，\(B = \{x \mid x^2 - 3x + 2 = 0\}\)，则 \(A\) 与 \(B\) 的关系是（ ）
A. \(A \subseteq B\)
B. \(B \subseteq A\)
C. \(A = B\)
D. \(A \not\subset B\)
解 \(x^2 - 3x + 2 = 0\) → \((x-1)(x-2)=0\) → \(B = \{1, 2\}\)。
所以 \(A = B\)。
📘 期中/期末★★ 中档
（2024 珠海期末）已知集合 \(A = \{1, 2, a\}\)，\(B = \{1, 2, 3\}\)，若 \(A \subseteq B\)，则 \(a\) 的值可以是（ ）
A. \(0\)
B. \(1\)
C. \(2\)
D. \(3\)
\(A \subseteq B\) 表示 A 中所有元素都在 B 中。
\(a\) 必须是 B 中已有的元素，即 1、2、3。
但 A 中已有 1、2，所以 a 不能是 1 或 2（否则集合有重复元素），因此 \(a = 3\)。
🎯 高考★★ 中档
（2021 广东高考）已知集合 \(A = \{1, 2\}\)，\(B = \{1, 2, 3, 4\}\)，则满足 \(A \subseteq C \subseteq B\) 的集合 \(C\) 的个数为（ ）
A. \(2\)
B. \(3\)
C. \(4\)
D. \(8\)
C 必须包含 A 中的 1、2，且从 \(B \setminus A = \{3, 4\}\) 中任意选择元素加入。
\(\{3,4\}\) 有 2 个元素，子集个数为 \(2^2 = 4\)。
📘 期中/期末★★ 中档
（2024 中山期末）已知集合 \(A = \{x \mid -1 < x < 3, x \in \mathbb{Z}\}\)，则集合 \(A\) 的非空真子集个数为（ ）
A. \(3\)
B. \(6\)
C. \(7\)
D. \(14\)
\(A = \{0, 1, 2\}\)，有 3 个元素。
非空真子集个数 = 子集个数 − 空集 − 本身 = \(2^3 - 2 = 6\)。
⚠️ 注意：\(-1 < x < 3\) 且 \(x \in \mathbb{Z}\)，所以 -1 和 3 都不取。
🎯 高考★★★ 综合
（2020 广东高考改编）已知集合 \(A = \{1, 2\}\)，\(B = \{x \mid ax = 2\}\)，若 \(B \subseteq A\)，则实数 \(a\) 的取值集合为（ ）
A. \(\{0, 1, 2\}\)
B. \(\{0, 1, \frac{1}{2}\}\)
C. \(\{0, 1, 2\}\)
D. \(\{0, 1, 2, \frac{1}{2}\}\)
⚠️ 分类讨论：
① 若 \(a = 0\)，方程 \(0 \cdot x = 2\) 无解 → \(B = \varnothing\) → \(B \subseteq A\) ✅
② 若 \(a \neq 0\)，\(x = \frac{2}{a}\)，要 \(B \subseteq A\)，则 \(\frac{2}{a}\) 必须是 1 或 2。
\(\frac{2}{a} = 1\) → \(a = 2\)；\(\frac{2}{a} = 2\) → \(a = 1\)。
合并：\(a = 0, 1, 2\)。
🎯 高考★★★ 综合
（2019 全国卷改编）已知集合 \(A = \{x \mid x^2 - 5x + 6 = 0\}\)，\(B = \{x \mid x \in \mathbb{N} \text{ 且 } x < 3\}\)，则 \(A\) 与 \(B\) 的关系是（ ）
A. \(A \subset B\)
B. \(B \subset A\)
C. \(A = B\)
D. \(A \cap B = \varnothing\)
解 \(A\)：\(x^2 - 5x + 6 = 0\) → \((x-2)(x-3)=0\) → \(A = \{2, 3\}\)。
\(B = \{x \in \mathbb{N} \mid x < 3\}\) → \(B = \{0, 1, 2\}\)。
\(A \cap B = \{2\}\)，所以 \(A \cap B \neq \varnothing\)。
但 A 和 B 互相不包含。
🎯 高考★★★ 综合
（2023 广东高考模拟）已知集合 \(A = \{x \mid x = 2n, n \in \mathbb{Z}\}\)，\(B = \{x \mid x = 4n, n \in \mathbb{Z}\}\)，则（ ）
A. \(B \subset A\)
B. \(A \subset B\)
C. \(A = B\)
D. \(A \cap B = \varnothing\)
A 是所有偶数，B 是所有 4 的倍数。
所有 4 的倍数都是偶数，但偶数不一定是 4 的倍数（如 2、6）。
所以 \(B \subset A\)（B 是 A 的真子集）。
