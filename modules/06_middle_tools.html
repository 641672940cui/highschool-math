因式分解 · 韦达定理 · 端点判断 —— 高考集合题的“三大基石”
① 因式分解 拆快递
🧸 生活比喻：因式分解 = “拆快递”
x² + bx + c = 一个快递箱，里面装了 两个小盒子
两个数的和 = b（盒子的宽度），两个数的积 = c（盒子的面积）
任务：找到两个数，让它们 相加 = b，相乘 = c
📌 Part A · 十字相乘（5种必背模板）
x²+5x+6
(x+2)(x+3)
x²−5x+6
(x−2)(x−3)
x²+x−6
(x+3)(x−2)
x²−x−6
(x−3)(x+2)
x²+2x−3
(x+3)(x−1)
💡 验算小习惯：写完后 展开回去，3 秒验算，避免 80% 的错误。
分解因式：x² − 5x + 6
A. (x − 2)(x − 3)
B. (x − 1)(x − 6)
C. (x + 2)(x + 3)
D. (x − 3)(x − 2)
(x − 2)(x − 3)
步骤：找两个数，和为 5，积为 6 → 2 和 3。
⚠️ (x − 2)(x − 3) 和 (x − 3)(x − 2) 等价，顺序不影响。
分解因式：x² − 7x + 12
A. (x − 3)(x − 4)
B. (x − 2)(x − 6)
C. (x + 3)(x + 4)
D. (x − 4)(x − 3)
(x − 3)(x − 4)
步骤：找两个数，和为 7，积为 12 → 3 和 4。
分解因式：x² − 2x − 3
A. (x − 3)(x + 1)
B. (x − 1)(x + 3)
C. (x + 3)(x − 1)
D. (x − 2)(x + 1)
(x − 3)(x + 1)
步骤：找两个数，和为 2，积为 −3 → 3 和 −1。
⚠️ 常数项为负 → 两根异号，大的为正。
分解因式：x² + 5x + 6
A. (x + 2)(x + 3)
B. (x − 2)(x − 3)
C. (x + 1)(x + 6)
D. (x − 1)(x − 6)
(x + 2)(x + 3)
步骤：找两个数，和为 5，积为 6 → 2 和 3。
⚠️ 一次项为正，常数项为正 → 两根都为正。
分解因式：x² + x − 6
A. (x + 3)(x − 2)
B. (x − 3)(x + 2)
C. (x + 6)(x − 1)
D. (x − 6)(x + 1)
(x + 3)(x − 2)
步骤：找两个数，和为 1，积为 −6 → 3 和 −2。
📌 Part B · 平方差公式
a² − b² = (a − b)(a + b)
🧸 生活比喻：边长为 a 的大正方形，挖掉边长为 b 的小正方形， 剩下的 L 形 可以拼成一个 长方形：长 (a+b)，宽 (a−b)。
识别特征：两项 · 都是平方 · 中间是减号
分解因式：x² − 9
A. (x − 3)(x + 3)
B. (x − 9)(x + 1)
C. (x − 3)²
D. (x + 3)²
(x − 3)(x + 3)
识别：x² − 3² → a = x，b = 3 → (x−3)(x+3)
分解因式：4x² − 25
A. (2x − 5)(2x + 5)
B. (4x − 5)(x + 5)
C. (2x − 5)²
D. (2x + 5)²
(2x − 5)(2x + 5)
识别：(2x)² − 5² → a = 2x，b = 5 → (2x−5)(2x+5)
分解因式：x⁴ − 1
A. (x²−1)(x²+1)
B. (x²−1)²
C. (x²+1)²
D. (x−1)(x+1)
(x²−1)(x²+1) = (x−1)(x+1)(x²+1)
识别：(x²)² − 1² → a = x²，b = 1。
⚠️ 注意：x²−1 还可以继续分解！
📌 Part C · 完全平方公式
a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
🧸 生活比喻：边长为 (a+b) 的大正方形，拆成 两个小正方形 + 两个长方形。
识别特征：三项 · 首尾两项是平方 · 中间项 = ±2 × 首项底数 × 尾项底数
独家技巧：中间项 ÷ 2，再开平方 → 就知道另一个数
分解因式：x² + 6x + 9
A. (x + 3)²
B. (x − 3)²
C. (x + 3)(x − 3)
D. (x + 9)(x + 1)
(x + 3)²
识别：首项 x²，尾项 9 = 3²，中间项 6x = 2 × x × 3 → (x+3)²
分解因式：x² − 8x + 16
A. (x − 4)²
B. (x + 4)²
C. (x − 4)(x + 4)
D. (x − 8)(x + 2)
(x − 4)²
识别：首项 x²，尾项 16 = 4²，中间项 −8x = −2 × x × 4 → (x−4)²
分解因式：4x² + 12x + 9
A. (2x + 3)²
B. (2x − 3)²
C. (4x + 3)(x + 3)
D. (2x + 3)(2x − 3)
(2x + 3)²
识别：首项 (2x)²，尾项 9 = 3²，中间项 12x = 2 × 2x × 3 → (2x+3)²
② 韦达定理 根与系数
🧠 记忆口诀：“两根和 = −b/a，两根积 = c/a”
含参集合题中，韦达定理是 “连接参数 a 和两根” 的唯一桥梁。
方程 x² − 5x + 6 = 0 的两根之和为（ ）
A. 5
B. 6
C. −5
D. −6
A. 5
由韦达定理：两根和 = −b/a = −(−5)/1 = 5。
方程 x² − 5x + 6 = 0 的两根之积为（ ）
A. 5
B. 6
C. −5
D. −6
B. 6
由韦达定理：两根积 = c/a = 6/1 = 6。
若方程 x² − ax + 4 = 0 的两根分别为 x₁、x₂，则 x₁ + x₂ =（ ）
A. a
B. −a
C. 4
D. −4
A. a
由韦达定理：两根和 = −b/a = −(−a)/1 = a。
⚠️ 注意：a 是参数，不是常数。
若方程 x² − ax + 4 = 0 的两根分别为 x₁、x₂，则 x₁ · x₂ =（ ）
A. a
B. −a
C. 4
D. −4
C. 4
由韦达定理：两根积 = c/a = 4/1 = 4。
⚠️ 注意：a 在 b 的位置，所以两根积与 a 无关。
③ 端点判断 开闭区间
🧠 记忆口诀：“有等号 → 闭区间（能取），无等号 → 开区间（不能取）”
高考集合题中，端点取不取是区分“会做”和“做对”的关键。
集合 A = {x | x > 2}，则 2（ ）A
A. ∈
B. ∉
B. ∉
x > 2 是 开区间，2 本身不在集合里。
集合 A = {x | x ≥ 2}，则 2（ ）A
A. ∈
B. ∉
A. ∈
x ≥ 2 是 闭区间，2 在集合里。
已知 U = R，A = {x | x > 2}，则 ∁UA =（ ）
A. {x | x < 2}
B. {x | x ≤ 2}
B. {x | x ≤ 2}
x > 2 的补集：x ≤ 2。
⚠️ 注意：2 不在 A 里，所以在补集里，要取等号。
已知 U = R，A = {x | x ≥ 2}，则 ∁UA =（ ）
A. {x | x < 2}
B. {x | x ≤ 2}
A. {x | x < 2}
x ≥ 2 的补集：x < 2。
⚠️ 注意：2 在 A 里，所以不在补集里，不能取等号。
已知 A = {x | −1 < x ≤ 3}，则以下说法正确的是（ ）
A. −1 ∈ A 且 3 ∈ A
B. −1 ∉ A 且 3 ∈ A
C. −1 ∈ A 且 3 ∉ A
D. −1 ∉ A 且 3 ∉ A
B. −1 ∉ A 且 3 ∈ A
−1 是 开区间（不取），3 是 闭区间（取）。
⚠️ 这是高考最爱的 “混合区间” 陷阱！
